# 노하우집 후속 개발 과제

현재 MVP 범위에는 포함하지 않지만, 이후 개발 시 검토할 작업을 기록한다.

## 내 학습 화면을 클래스 목록과 상세 화면으로 분리

- 기록일: 2026-08-03
- 상태: 추후 개발
- 대상: 수강생 화면 > 내 학습
- 개발 여부: 현재는 개발하지 않고 과제로만 기록

### 배경

현재 내 학습 화면은 한 클래스의 영상, 자료, 운영 안내, FAQ 등 상세 정보를 화면 안에 함께 표시한다. 수강하는 클래스가 많아진 상태에서 클래스별 상세 정보가 한 페이지에 계속 쌓이면 스크롤이 지나치게 길어지고, 한 번에 렌더링하거나 불러오는 요소와 데이터가 많아져 초기 표시 및 화면 상호작용이 느려질 수 있다.

### 변경 방향

내 학습 첫 화면에는 수강 중이거나 수강했던 클래스를 요약 카드 또는 목록 형태로 표시한다. 사용자가 특정 클래스를 클릭하면 해당 클래스 안쪽의 전용 상세 화면으로 이동하여 다음 정보를 확인하고 관리하도록 변경한다.

- 이어서 학습 및 진도
- 영상 커리큘럼
- 제공 자료
- 운영 안내와 일정
- 클래스 FAQ

목록 화면에 모든 클래스의 상세 정보를 한꺼번에 담지 않고, 사용자가 선택한 클래스의 정보만 상세 화면에서 불러오고 표시하는 구조를 기본 방향으로 한다.

### 구현 시 함께 결정할 사항

- 수강 중, 수강 예정, 수강 종료 클래스의 구분과 정렬 기준
- 클래스 상세 진입 방식: 별도 페이지 또는 현재 화면 내부 전환
- 상세 화면에서 목록으로 돌아올 때 스크롤 위치와 선택 상태 유지
- 마지막으로 보던 강의와 학습 진도 유지
- 클래스가 매우 많을 때 페이지네이션 또는 점진적 로딩 적용 여부
- 모바일에서 목록과 상세 화면 사이의 이동 방식

### 완료 기준

1. 내 학습 첫 화면에는 클래스별 요약 정보만 표시한다.
2. 클래스를 클릭해야 해당 클래스의 영상, 자료, 운영 안내와 FAQ가 표시된다.
3. 선택하지 않은 클래스의 상세 영역은 최초 화면에서 렌더링하지 않는다.
4. 상세 화면에서 목록으로 자연스럽게 돌아갈 수 있고 기존 탐색 상태가 유지된다.
5. 수강 클래스가 많아져도 첫 화면의 길이와 초기 표시 비용이 클래스별 전체 상세 구조보다 크게 증가하지 않는다.
