# 전자책 뷰어 미리보기

- 화면: `ebook-reader.html`
- PDF.js: 5.4.624, Apache-2.0. 라이선스는 `vendor/pdfjs/LICENSE`에 포함.
- 원본 배포: https://www.npmjs.com/package/pdfjs-dist/v/5.4.624
- 샘플: `assets/ebooks/knowhowzip-reading-sample.pdf` (자체 제작 예시 문서 6페이지)
- 로컬 실행: `python3 -m http.server 8879 --bind 127.0.0.1 --directory knowhowzip-site`
- 접속: http://127.0.0.1:8879/ebook-reader.html

## 구현 범위

PDF.js canvas 렌더링 및 텍스트 레이어, 페이지 이동·번호 입력, 확대/축소·너비 맞춤, 목차, 책갈피, 브라우저별 마지막 페이지 저장, 모바일 접이식 목차, 오류 안내를 제공한다. 기존 학습/결제 흐름과 분리된 디자인 미리보기다. 라이브러리와 PDF는 로컬에서 제공한다.

## 다운로드 제한의 의미

다운로드·인쇄 버튼을 제공하지 않고 인쇄용 스타일에서 본문을 제외한다. 이는 UI 제한이며 DRM이나 원본 파일 저장 방지가 아니다. 샘플 PDF는 정적 공개 파일이므로 직접 URL로 접근 가능하다. 우클릭·브라우저 단축키를 가로채지 않는다. 표시된 워터마크는 예시 UI이며 제거 가능한 HTML 요소다.

유료 콘텐츠 적용 전 구매자 권한을 서버에서 검증하고, 비공개 파일 저장소 및 짧은 유효기간의 파일 접근 권한을 연결해야 한다. 필요하면 서버에서 구매자별 워터마크를 PDF 자체에 삽입한다. 이 경우에도 이미 브라우저에 전달된 파일의 저장이나 화면 캡처를 완전히 방지할 수 없다. 책갈피·읽기 위치의 기기 간 동기화도 별도 서버 구현이 필요하다.

기본 문서는 예시 데이터다. 관리자에서 등록한 PDF는 `?book=콘텐츠ID`로 IndexedDB에서 읽으며, 입력한 제목·목차와 실제 페이지 수를 표시한다. 사용자 구매 권한 연결과 서버 저장은 후속 구현 범위다.


## 2026-11-26 유형별 관리자 개정

- IA: `docs/content-ia-proposal.html` (영상형/전자책형 분리 개정안).
- 관리자: `creator-admin.html#classes` 콘텐츠 관리, `#products` 판매 관리.
- 등록: `#content-type`, `#sale-type`에서 유형 선택.
- 기존 영상 편집기를 유지하며 연결 목록에서 전자책은 제외한다.
- 전자책은 PDF 검증(파일 확장자·크기·파싱), 페이지 수 자동 확인, 목차 페이지 범위 검증 후 저장한다.
- 콘텐츠와 판매 메타데이터는 `nhz-content-types-v1` localStorage, PDF와 목차는 `knowhowzip-ebook-preview` IndexedDB에 저장한다.
- 전자책 판매는 같은 유형 1권을 연결하고 가격·기간·공개 상태를 저장한다. 연결된 전자책 원본은 조회만 제공한다.
- 기존 영상의 복제·삭제 기능을 유지한다. 전자책도 같은 목록 동작을 사용한다.
- 전체 사용자 판매 페이지, 주문·정산·수강생 화면의 유형 확장은 아직 연결하지 않았다.

### 확인한 흐름

실제 6페이지 PDF 선택 → 페이지 수 감지 → 제목/목차 저장 → 목록 표시 → 등록한 PDF 뷰어 열기. 전자책 판매 저장 → 새로고침 유지. 기존 영상형 편집 → 연결 후보에서 전자책 제외. JavaScript 구문 검사 완료.
